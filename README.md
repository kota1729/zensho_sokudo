# 全商ビジネス文書検定 速度部門 模擬練習＆自動採点ツール

全商ビジネス文書検定（速度部門）をイメージした、ブラウザだけで動く練習ツールです。
サーバー・インストール・Wordファイルは不要です。

課題はWebページ上の一覧から選ぶだけで、練習と自動採点ができます。

## 使い方

### オンラインで使う（GitHub Pages）
1. このリポジトリの **Settings → Pages** で、Source を `Deploy from a branch`、Branch を `main` / `(root)` にして保存
2. 表示された URL（`https://<ユーザー名>.github.io/<リポジトリ名>/`）を開く

### ローカルで使う
リポジトリをダウンロードして `index.html` をブラウザで開くだけで動きます（`file://` でも可）。

## 練習の流れ
1. 「受験する級」を選ぶ → 課題の一覧から選ぶ（「🎲 ランダム」も可）
2. 「試験開始」 → 3秒のカウントダウン（この間にIMEを日本語入力に切り替え）→ 10分間入力
3. 10分で自動採点。続きを打つ場合は「タイピングを続ける」。途中終了は `Ctrl+Enter`
4. 誤字（赤）・脱字（黄）・余分字（青）が色分けで表示され、記録は「📊 記録を見る」から確認できます

## ファイル構成
```
index.html        練習・採点ページ
js/common.js      共通処理（課題文の整形）
data/tasks.js     組み込み課題（1級13件・2級14件・3級39件）
```

### 課題を追加・差し替えるには
`data/tasks.js` の `window.ZENSHO_TASKS` に `{ "no": "40", "text": "本文" }` を追加します。

## オンライン対戦

1. HTTPSで公開した `index.html` を開き、「オンラインで対戦」を選びます。ローカルではプロジェクトフォルダーで `py -m http.server 8000` を実行し、`http://localhost:8000/` を開きます。
2. 両者が名前と同じ合言葉を入力し、「合言葉で相手を募集・検索」を押します。先に押した側が部屋を作り、次に押した側は同じ部屋へ自動参加します。接続コードは不要です。
3. どちらかが課題を提案し、相手が同意します。同じ課題・本文を双方で確認し、両者が準備完了を押すと、カウントダウン後に始まります。
4. 入力終了後は相手の終了を待ちます。結果は完了、正確率、正解文字数/分の順に比較します。

### ネットワーク上の制約

PeerJS Cloud がWebRTCの待ち合わせと接続情報交換を仲介します。部屋IDはサイトURLと合言葉から生成されます。最初にボタンを押した側は相手が接続するまでページを開いたままにします。後から押した側は部屋を約48秒間検索します。同じサイト・同じ合言葉で同時に利用できる部屋は一つです。対戦データはRTCDataChannelでブラウザー間を直接通信します。公開STUNを利用しますが、TURN中継はないため、厳しいNAT、VPN、ファイアウォール等では接続できない場合があります。

合言葉は部屋を探す文字列で、本人確認用のパスワードではありません。推測しやすい短い合言葉は第三者に見つけられるおそれがあります。PeerJS Cloudへ部屋ID（合言葉のハッシュ）とWebRTC接続情報が送られます。名前・入力状況・対戦データは接続後のP2P通信で送られます。
