# 全商ビジネス文書検定 速度部門 模擬練習＆自動採点ツール

全商ビジネス文書検定（速度部門）をイメージした、ブラウザだけで動く練習ツールです。
サーバー・インストール・Wordファイルは不要です。

課題はWebページ上の一覧から選ぶだけで、練習と自動採点ができます。

## 使い方

### オンラインで使う（GitHub Pages）
1. このリポジトリの **Settings → Pages** で、Source を `Deploy from a branch`、Branch を `main` / `(root)` にして保存
2. 表示された URL（`https://<ユーザー名>.github.io/<リポジトリ名>/`）を開く

### ローカルで使う
リポジトリをダウンロードして `index.html` をブラウザで開くだけで動きます（`file://` でも可）。

## 練習の流れ
1. 「受験する級」を選ぶ → 課題の一覧から選ぶ（「🎲 ランダム」も可）
2. 「試験開始」 → 3秒のカウントダウン（この間にIMEを日本語入力に切り替え）→ 10分間入力
3. 10分で自動採点。続きを打つ場合は「タイピングを続ける」。途中終了は `Ctrl+Enter`
4. 誤字（赤）・脱字（黄）・余分字（青）が色分けで表示され、記録は「📊 記録を見る」から確認できます

## オンライン対戦（2人）
サーバーは使わず、ブラウザ同士が直接通信（WebRTC）して対戦します。

1. 練習ページの「🥊 オンライン対戦」を押すと、「部屋を作る」「部屋に参加する」が出ます
2. **部屋を作る**: 自動発行された6桁の部屋番号が表示されます。ニックネームを入力すると「部屋を作成」を押せます。番号を相手に伝えてください
3. **部屋に参加する**: ニックネームと6桁の部屋番号（半角数字のみ入力可）を入れて「参加する」。該当する部屋がなければ「見つかりませんでした」と表示されます
4. 部屋で **級** と **課題（第何回／ランダム）** を選びます。どちらの人が変更してもOKで、変更すると準備はやり直しになり、**2人とも「準備OK」を押した時点で確定**します。「ランダム」は2人の乱数の合計で決まります（同じ部屋の再戦では出題済みを避けます）
5. 「準備OK」を押すとボタンが灰色になり、退室ボタンの横に「準備キャンセル」が出ます
6. 2人とも準備OKになると**対戦画面に切り替わってカウントダウンが始まります**（自分の画面と相手の画面が見える位置に自動で移動します）
7. 自分の画面はいつも通りで、その下に相手の「お手本」と「入力」が小さくリアルタイムで表示されます。先に終えた人は「相手の画面を大きく見る」で相手の様子を見られます
8. 採点画面の上に勝敗が表示され、両者が終わるとお互いの採点結果・かかった時間が出ます（得点＝総字数−エラー数 → エラーの少なさ → 終了の早さ の順）。「ロビーに戻る（再戦）」で同じ部屋のまま再戦できます

- 対戦中は「改行を1文字として数える」設定に固定されます（採点条件をそろえるため）
- 対戦の結果も「📊 記録を見る」に残ります（課題名に「・対戦」と付きます）
- 3人目が同じ部屋番号で入ると「満員」になります
- 相手を見つける仲介に、公開リレー（MQTT / BitTorrent / Nostr）とライブラリ [Trystero](https://github.com/dmotz/trystero)（jsDelivr CDN経由）を使います。合言葉はハッシュ化して部屋名にし、通信の暗号化にも使います
- **学校のネットワーク等で WebRTC や WebSocket が制限されていると接続できません**。その場合はスマホのテザリングなど別回線でお試しください
- 勝敗判定は各自のブラウザで行っており、改造すれば不正も可能です（練習用の遊びとしての利用を想定しています）

## ファイル構成
```
index.html        練習・採点ページ
js/common.js      共通処理（課題文の整形）
js/battle.js      オンライン対戦
data/tasks.js     組み込み課題（1級13件・2級14件・3級39件）
```

### 課題を追加・差し替えるには
`data/tasks.js` の `window.ZENSHO_TASKS` に `{ "no": "40", "text": "本文" }` を追加します。
