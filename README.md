# 全商ビジネス文書検定 速度部門 模擬練習＆自動採点ツール

全商ビジネス文書検定（速度部門）をイメージした、ブラウザだけで動く練習ツールです。
サーバー・インストール・Wordファイルは不要です。

課題はWebページ上の一覧から選ぶだけで、練習と自動採点ができます。

## 使い方

### オンラインで使う（GitHub Pages）
1. このリポジトリの **Settings → Pages** で、Source を `Deploy from a branch`、Branch を `main` / `(root)` にして保存
2. 表示された URL（`https://<ユーザー名>.github.io/<リポジトリ名>/`）を開く

### ローカルで使う
リポジトリをダウンロードして `index.html` をブラウザで開くだけで動きます（`file://` でも可）。

## 練習の流れ
1. 「受験する級」を選ぶ → 課題の一覧から選ぶ（「🎲 ランダム」も可）
2. 「試験開始」 → 3秒のカウントダウン（この間にIMEを日本語入力に切り替え）→ 10分間入力
3. 10分で自動採点。続きを打つ場合は「タイピングを続ける」。途中終了は `Ctrl+Enter`
4. 誤字（赤）・脱字（黄）・余分字（青）が色分けで表示され、記録は「📊 記録を見る」から確認できます

## ファイル構成
```
index.html        練習・採点ページ
js/common.js      共通処理（課題文の整形）
data/tasks.js     組み込み課題（1級13件・2級14件・3級39件）
```

### 課題を追加・差し替えるには
`data/tasks.js` の `window.ZENSHO_TASKS` に `{ "no": "40", "text": "本文" }` を追加します。

## オンライン対戦

1. `index.html` から「オンラインで対戦」を開き、両者が名前と同じ合言葉を入力します。
2. Aは「部屋を作成してOfferを作る」を押し、Offer欄のコードをコピーしてBに送ります。
3. BはOfferを貼り付けて「Offerを適用してAnswerを作る」を押し、AnswerコードをAへ送ります。
4. AはAnswerを貼り付けて「Answerを適用して接続」を押します。接続後、合言葉が照合されます。
5. どちらかが課題を提案し、相手が同意します。同じ課題・本文を双方で確認してから両者が「準備完了」を押すと、カウントダウン後に始まります。
6. 入力終了後は相手の終了を待ちます。結果の比較順は完了、正確率、正解文字数/分です。

### 起動とネットワーク上の制約

GitHub Pages などの HTTPS 配信を推奨します。ローカルで試す場合は `localhost` から開いてください（通常の `file://` はブラウザによって WebRTC の制約が出ることがあります）。2台は別々の端末・ブラウザで同じファイルを開きます。

Offer/AnswerコードにはSDPと収集したICE候補が入ります。ICE収集完了後に全体をコピーして交換してください。コード交換は初回接続のたびに必要です。対戦中はRTCDataChannelで直接通信し、サーバー、データベース、専用シグナリング、TURN中継は使いません。公開STUNへの問い合わせは行いますが、厳しいNAT、VPN、ファイアウォール等ではP2P接続できない場合があります。その場合の接続保証や自動再接続はありません。接続をリセットし、両者でコード交換をやり直すかネットワークを変更してください。

合言葉はDTLSで保護されたDataChannel上で照合しますが、利用者の本人確認をするパスワードではありません。対戦後の「もう一度対戦」は同じ接続を保ったまま課題選択からやり直します。
